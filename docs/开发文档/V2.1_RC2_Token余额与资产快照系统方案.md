# 7. 资产变化分析

识别：

## 大额进入

规则：

    amount > P95

输出：

-   来源地址
-   Token
-   金额

------------------------------------------------------------------------

## 快速清空

模式：

    大额进入

    ↓

    短时间转出

标记：

high_risk_flow

------------------------------------------------------------------------

## 余额异常下降

计算：

    balance_before

    -

    balance_after
