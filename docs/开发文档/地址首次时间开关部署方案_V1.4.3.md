# 地址首次时间开关部署方案（V1.4.3）

> 适用项目：`E:\codex\bsc_analytics`

## 一、目标

地址分析默认分析时间调整为：

-   **开始时间：地址首次出现时间（First Seen）**
-   **结束时间：当前时间**

同时，**前端必须提供一个开关**，允许用户决定是否启用该逻辑。

------------------------------------------------------------------------

# 二、前端需求

默认：

``` text
☑ 从地址首次出现开始分析
```

页面效果：

    分析时间

    ☑ 从地址首次出现开始

    首次出现：
    2021-06-12 10:21 UTC

    开始时间：
    （禁用）

    结束时间：
    当前时间

关闭开关后：

    分析时间

    ☐ 从地址首次出现开始

    开始时间：
    [日期选择器]

    结束时间：
    [日期选择器]

规则：

-   开启时：
    -   开始时间输入框禁用
    -   后端自动计算 first_seen_time
-   关闭时：
    -   开始时间输入框启用
    -   用户必须选择开始时间
    -   未填写禁止提交

------------------------------------------------------------------------

# 三、请求参数

``` json
{
  "chain_id":"bsc",
  "address":"0x...",
  "use_first_seen":true,
  "start_time":null,
  "end_time":null
}
```

关闭开关：

``` json
{
  "use_first_seen":false,
  "start_time":"2025-01-01T00:00:00Z",
  "end_time":"2026-07-30T00:00:00Z"
}
```

------------------------------------------------------------------------

# 四、后端逻辑

    if use_first_seen == true
        start = first_seen_time
    else
        start = request.start_time

    end = request.end_time ?? now()

后端不能信任前端传入的 first_seen_time，必须自行查询。

------------------------------------------------------------------------

# 五、首次出现时间获取

EOA：

-   最早交易
-   最早收到币
-   最早发送币
-   最早 Token Transfer
-   最早 Trace

取最小区块：

    MIN(block_number)

Contract：

优先：

    Contract Creation

否则回退：

    Earliest Activity

# 九、接口

获取首次时间：

    GET /api/crypto/addresses/{chain}/{address}/first-seen

分析：

    POST /api/crypto/address-analysis

------------------------------------------------------------------------

# 十、测试

必须验证：

-   默认开启
-   可关闭
-   开启时开始时间不可编辑
-   关闭时必须填写开始时间
-   EOA First Seen
-   Contract Creation
-   SQD 503
-   PARTIAL
-   NOT_FOUND
-   批量分析

------------------------------------------------------------------------

# 十一、验收标准

-   默认开启首次时间
-   用户可关闭
-   后端统一解析生效时间
-   EOA 使用 First Seen
-   Contract 优先使用 Creation Time
-   SQD 异常不影响手动时间模式
-   所有分析任务保存最终生效时间范围
