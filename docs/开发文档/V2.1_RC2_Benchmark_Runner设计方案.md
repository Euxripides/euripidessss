# V2.1 RC2 Benchmark Runner设计方案

版本：V2.1 RC2\
状态：设计阶段\
目标：构建统一压力测试执行框架

------------------------------------------------------------------------

# 1. 项目背景

V2.1 RC2 已完成：

-   Address Planner压力测试
-   Chunk系统压力测试
-   Job状态测试
-   Provider故障恢复
-   Crash Resume

下一阶段进入数据处理链路压力测试：

    Address
     ↓
    Planner
     ↓
    Chunk
     ↓
    Provider
     ↓
    Dataset
     ↓
    Parquet
     ↓
    DuckDB

Benchmark Runner用于：

-   自动生成测试数据
-   执行压力任务
-   采集性能指标
-   输出标准化报告
-   支持版本性能回归

------------------------------------------------------------------------

# 2. 设计原则

## 架构冻结

禁止：

-   修改Job模型
-   修改Provider接口
-   修改Dataset Registry
-   修改Chunk结构

允许：

-   新增benchmark目录
-   新增metrics采集
-   新增测试数据生成器
-   新增报告输出

# 5. CLI设计

Parquet测试：

    bsc benchmark parquet --rows 10000000

DuckDB测试：

    bsc benchmark duckdb --file transactions.parquet

Pipeline测试：

    bsc benchmark pipeline --addresses 500000

全量测试：

    bsc benchmark all

------------------------------------------------------------------------

# 6. 测试模块

## Parquet Writer

测试：

-   100万 rows
-   1000万 rows
-   5000万 rows

指标：

-   rows/s
-   MB/s
-   CPU
-   RAM
-   SSD写入
-   文件大小

------------------------------------------------------------------------

## DuckDB

测试：

-   transactions.parquet
-   logs.parquet
-   tokens.parquet

场景：

-   全表扫描
-   Group By
-   时间过滤
-   Join查询

指标：

-   execution time
-   memory usage
-   scan rows

------------------------------------------------------------------------

## Pipeline

模拟：

    Address Input
     ↓
    Planner
     ↓
    Chunk
     ↓
    Download
     ↓
    Dataset
     ↓
    Parquet
     ↓
    Index

测试规模：

  等级          地址
  -------- ---------
  Small        10000
  Medium      100000
  Large       500000
  Max        1000000
