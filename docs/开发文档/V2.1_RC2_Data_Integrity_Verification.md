# V2.1 RC2 Data Integrity Verification

版本：V2.1 RC2

## 目标

验证：

SQD → Parser → Dedup → Parquet → DuckDB

完整链路的数据一致性。

目标：

-   0数据丢失
-   0错误重复写入
-   Schema正确
-   文件可恢复

## 验证内容

### 数据一致性

校验：

    SQD Rows
    =
    Parser Rows
    =
    Parquet Rows
    =
    DuckDB COUNT

记录：

-   source_rows
-   parsed_rows
-   unique_rows
-   parquet_rows
-   duckdb_rows

### Log唯一性

唯一键：

    chain_id
    +
    block_number
    +
    transaction_hash
    +
    log_index

统计：

-   raw_logs
-   unique_logs
-   duplicate_logs

重复拆分：

-   duplicate_logs_in_chunk
-   duplicate_logs_cross_chunk

确认跨chunk地址交集属于业务重复。

## Parquet验证

检查：

-   文件存在
-   文件大小
-   Schema
-   Checksum

## DuckDB验证

验证：

    DuckDB COUNT = Parquet Rows

并检查：

    COUNT(*) = COUNT(DISTINCT unique_key)

## Checkpoint恢复

流程：

    运行50%
    ↓
    停止服务
    ↓
    重启
    ↓
    Resume

验证：

-   已完成Chunk跳过
-   未完成Chunk恢复
-   无重复写入

## 数据损坏测试

模拟：

-   Parquet修改
-   Checksum变化

验证：

-   检测失败
-   禁止进入READY状态
