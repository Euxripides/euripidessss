# 资金流向图 V3 — 单人深度调查分析工作台升级方案
## 时间回放 · 调查透镜 · 路径查询 · 假设验证 · 跨资产追踪

> 本阶段建立在 V2“白底单人调查工作台”之上，不再只优化样式，而是把资金流向图升级成真正的调查分析引擎前端。
>
> V2 已解决：
> - 白底与低噪声
> - 关键路径
> - 地址 / 实体视图
> - 自动补数
> - 重点节点 / 路径
> - 图与智能下载、结果数据、智能调查联动
>
> V3 继续解决：
> - 资金什么时候移动
> - 哪些路径最重要
> - Swap / Bridge 后如何继续追
> - 两个时间段 / 多个根地址如何比较
> - 如何让用户直接提出调查假设
> - 如何让系统主动建议下一步调查动作

# 3. Temporal Graph Replay — 时间轴资金回放

当前大图一次性铺满全部历史关系，很难判断：

```text
第一步发生了什么
什么时候拆分
什么时候归集
多久后进入交易所
什么时候形成沉淀
```

建议新增底部时间轴：

```text
┌────────────────────────────────────────────────────────┐
│ ▶  |◀  2026-07-20 12:30  ▶|    1x  2x  5x             │
│ ━━━━━━━━━●━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━             │
│ 大额入金   拆分      归集      Bridge      Exchange    │
└────────────────────────────────────────────────────────┘
```

支持：

```text
播放 / 暂停
逐事件
逐小时
逐天
拖动时间
播放速度
```

随着时间推进：

```text
新节点淡入
新边出现
累计金额变化
余额变化
路径逐步形成
```

重点不是动画，而是让调查者看清资金行为顺序。

# 6. Investigation Lenses — 调查透镜

不要让用户靠几十个复选框找答案。

顶部新增：

```text
调查透镜
```

一键切：

```text
资金主干
大额流向
快速转移
资金沉淀
获利
交易所落点
风险暴露
跨链
```

---

# 7. 资金主干透镜

只保留承担主要资金价值的路径。

例如：

```text
只显示能够解释 80% / 90% / 95% 资金的边
```

比“金额 > 固定阈值”更适应不同案件规模。

---

# 8. 快速转移透镜

突出：

```text
收到资金后 <10min / <1h / <24h 继续转出
```

适合识别：

```text
中转
归集
快速分层
```

---

# 9. 沉淀透镜

突出：

```text
高净流入
低出金
长持有
当前余额高
```

直接消费 Settlement Detection 结果。

---

# 10. 获利透镜

使用 Profit Attribution：

```text
高获利节点
获利来源
获利去向
同实体内部转移排除
```

---

# 11. 交易所落点透镜

只强化：

```text
CEX Deposit
Hot Wallet
Custodian
Payment Service
```

其他节点降低透明度。

---

# 12. Lens 组合

允许：

```text
[交易所落点] + [大额] + [最近30天]
```

得到：

```text
最近30天大额交易所落点路径
```

并支持保存个人 Lens Preset：

```text
盘古：大额USDT沉淀
FIST获利路径
交易所落点快速排查
近30天高风险外流
```

# 13. Path Query Builder — 路径查询器

现有：

```text
上游 / 下游 / 1层 / 2层
```

还不够。

新增无 SQL 的路径查询器：

```text
起点
终点类型
Token
金额
时间
最大跳数
必须经过
排除实体
节点类型
边类型
```

示例：

```text
从 0xAAA 出发
金额 >= 100,000 USDT
5跳以内
最终进入交易所
排除 DEX Router / Pool
时间 2026-01-01 ~ 2026-08-08
```

# 14. Path Query 结果

```text

Path #3  410K USDT  2 hops  Dormant     Score 86
```

点击：

```text
在图中查看
```

才展开并高亮。

# 15. Hypothesis Workspace — 调查假设工作区

单人调查常见假设：

```text
这些地址可能属于同一控制主体
这个地址可能只是中转
获利最终可能进入某交易所
这些地址可能共享资金来源
```

系统应支持把假设结构化保存并验证。

---

# 16. 假设状态

```text
DRAFT
TESTING
SUPPORTED
WEAK
CONTRADICTED
UNRESOLVED
```

多选节点后：

```text
[建立假设]
```

例如：

```text
这些地址可能属于同一实体？
```

自动调用：

```text
Entity Intelligence
共同 Sweep
共同 Funding
Temporal Pattern
Counterparty Overlap
Flow Pattern
```

输出：

```text
支持证据
反证
置信度
```

反证必须展示，避免过度归因。

# 17. Asset Continuity — 跨资产连续追踪

真实资金路径可能：

```text
USDT
↓ Swap
BNB
↓ Bridge
ETH
↓ USDC
↓ Exchange
```

如果只按 Token Transfer 看，路径会断。

V3 增加：

```text
Value Continuity
```

---

# 18. Swap 连续性

把：

```text
USDT → Router → BNB
```

抽象成：

```text
100K USDT
↓ Swap
≈99.3K USD BNB
```

保留：

```text
原始资产
原始数量
USD估值
价格来源
价格时间
转换置信度
```

---

# 19. Bridge 连续性

跨链：

```text
BSC
↓ Bridge
ETH
```

不能分成两张完全独立图。

需要：

```text
Bridge In
Bridge Out
目标链地址
对应资产
估值
```

形成连续路径。

# 20. 两种追踪模式

### Token Mode
严格追同一 Token。

### Value Mode
允许经过 Swap / Bridge 后继续追踪等值资金。

# 21. Graph Diff — 图谱差异分析

支持比较：

```text
昨天 vs 今天
本周 vs 上周
时间段 A vs B
任务 v1 vs v2
```

突出：

```text
新增节点
新增边
金额明显增加
新交易所落点
新沉淀地址
新风险暴露
```

例如：

```text
过去7天新增：
+ 3 个交易所入金地址
+ 1 条 880K USDT 新路径
+ 2 个沉淀候选
+ 1 个风险节点
```

点击可在图中高亮变化。

# 22. Multi-Root Investigation — 多根地址联合调查

允许从多个根地址同时分析，例如：

```text
盘古多个入金地址
多个出金地址
多个获利地址
```

回答：

```text
是否有共同资金来源
是否最终进入同一交易所
是否共享中转节点
是否存在共同实体
```


# 24. Graph Reduction — 智能减噪

600 节点已经很密，V3 需要后端参与降噪。

自动折叠：

```text
低金额叶子
热门 Router
低价值合约
大量 Deposit 地址
同实体内部地址
重复一跳噪声
```

任何折叠都必须可解释：

```text
已折叠 128 个低价值地址
```

点击即可展开。

---

# 25. Value Coverage Reduction


# 27. Investigation Copilot — 下一步调查建议

不是让 Agent 控制图，而是给出下一步操作建议：

```text
1. B 收到 1.2M USDT 后 8 分钟全部转出，建议继续下游
2. C 当前保留 410K USDT，建议查看历史来源
3. D 已进入 Exchange X Deposit，可作为落点证据
4. E Coverage 仅 62%，建议补齐 Internal Transactions
```

每条建议必须可点击：

```text
[展开下游]
[查看沉淀]
[补齐数据]
[加入重点]
[加入报告]
```

# 42. Smart Download 深度联动

```text

+

+

```

```text

```

