# V2.1 RC2 项目交接上下文

## 项目目标

构建企业级区块链数据下载与分析系统，支持：

-   地址批量分析
-   Transactions
-   Logs
-   ERC20/BEP20 Transfer
-   NFT Transfer
-   Trace
-   Internal Transaction
-   Parquet 数据资产化
-   DuckDB 分析
-   多链扩展
