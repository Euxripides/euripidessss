# V2.1 RC2 动态地址扩展与智能采集路由方案

## 1. 背景

当前系统已经具备：

- 地址画像
- 资金流分析
- 地址图谱
- 风险分析
- Token余额
- 调查报告

目标：

实现分析过程中自动发现新地址，并根据地址类型选择不同采集方式。

---

## 2. 核心流程

```
目标地址

↓

分析

↓

发现关联地址

↓

地址评分

↓

实体识别

↓

选择采集方式

↓

增量数据获取

↓

继续分析
```

---

## 3. Dynamic Investigation Engine

负责：

- 地址发现
- 扩展队列
- 地址评分
- 采集决策

---

## 4. 地址发现队列

状态：

```
DISCOVERED
SCORING
APPROVED
ACQUIRING
COMPLETED
IGNORED
```

记录：

- address
- source
- amount
- token
- depth

---

## 5. 地址评分

Expansion Score：

```
资金金额

+

风险权重

+

关联强度

+

活跃度

-

实体惩罚
```

用于判断是否继续下载。

## 10. 验收标准

- 自动发现地址

- 自动选择采集方式
- 控制最大深度
- 控制最大地址数量
- 支持金额阈值过滤
