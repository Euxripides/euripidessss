# 链上分析平台 Frontend Design System + UI 重构方案 V1.0

## 1. 项目背景

当前链上分析平台已经具备：

-   多链数据采集（BSC / ETH / Base / Arbitrum）
-   SQD / AWS / RPC 数据源管理
-   Parquet + DuckDB 分析体系
-   地址画像
-   Token/NFT 分析
-   资金流向图谱
-   风险分析
-   智能调查闭环

随着功能增加，前端逐渐出现：

-   页面层级复杂
-   模块之间视觉不统一
-   信息密度过高
-   数据展示缺少分析平台体验
-   动画和交互不足
-   后续 Codex 持续开发容易产生 UI 混乱

因此需要建立统一 Frontend Design System。

# 15. Codex执行规则

Codex开发要求：

1.  禁止新增重复组件

2.  新页面必须复用 Design System

3.  所有动画必须统一入口

4.  所有颜色必须来自 Theme

5.  所有 Card 必须符合规范

6.  图谱组件必须独立
