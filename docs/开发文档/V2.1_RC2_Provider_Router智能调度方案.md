# V2.1 RC2 Provider Router智能调度方案

版本：V2.1 RC2\
状态：设计方案

------------------------------------------------------------------------

# 1. 背景

当前系统已经具备：

-   Provider Adapter
-   Provider Health
-   Capability
-   Router
-   Failover
-   Checkpoint
-   Dataset Registry

真实测试发现：

SQD具备真实BSC数据获取能力：

-   StreamLogs验证通过
-   StreamTraces验证通过
-   122,892真实交易处理通过

但公共SQD存在：

-   DNS异常
-   503限流
-   网络波动
-   服务不可达

因此Provider Router需要从：

    固定Provider调用

升级为：

    智能Provider调度系统

------------------------------------------------------------------------

# 2. 设计目标

实现：

    任务请求

    ↓

    Provider Router

    ↓

    自动选择最佳Provider

    ↓

    失败自动切换

    ↓

    任务继续执行

目标：

-   提升可用性
-   降低单点依赖
-   保证数据任务连续运行

# 8. Circuit Breaker集成

Provider状态：

    Healthy

    ↓

    Warning

    ↓

    Open

    ↓

    Recovery

规则：

连续：

    5次失败

进入：

    Open

    60秒

# 9. Chunk级调度

禁止：

    整个任务切换Provider

采用：

    Chunk独立调度

示例：

  Chunk   Provider   状态
  ------- ---------- ------
  001     SQD        完成
  002     SQD        完成
  003     SQD        失败
  004     RPC        完成

只恢复：

    003
