## 4. 高频交易检测

    transaction_frequency

公式：

    event_count / active_days

识别：

-   高频机器人
-   自动化账户
-   异常活跃地址

输出：

    top_active_addresses.csv

## 6. 地址关联分析

指标：

    shared_counterparty_score

算法：

    Jaccard =
    A∩B / A∪B

发现：

-   关联地址群
-   控制地址
-   协同交易行为
