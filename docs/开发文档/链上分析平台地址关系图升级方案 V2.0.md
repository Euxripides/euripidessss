# 链上分析平台地址关系图升级方案 V2.0

> 文档版本：V2.0  
> 目标仓库：`E:\codex\etl`  
> 基础文档：《加密货币交互式资金流向图技术设计与实施指南》  
> 技术栈：React 19、TypeScript 6、Vite 8、Ant Design 5、`@xyflow/react` 12、Go、Gin、DuckDB  
> 核心目标：将现有地址关系图升级为集资金关系、实时资产、统计分析、证据核验和 Agent 调查联动于一体的链上调查图谱工作台。

---

## 1. 升级目标

本次不是单纯替换图形样式，而是在现有交互式资金流向图基础上新增：

- 全局关系图和中心地址聚焦图
- 上游、下游、多层关系查询
- 实时 BNB、USDT、USDC 及重点 Token 余额
- 地址统计、子图统计、全局图统计
- 资金来源和去向集中度
- 活跃度、时间分布和净流量
- 交易所、合约、EOA、Bridge、Mixer 等节点分类
- 余额快照和历史对比
- Evidence Layer 证据保存
- Investigation Agent 一键调查
- 多 RPC 容灾、缓存、批量查询和限流保护

最终交互：

```text
打开资金关系图
    ↓
搜索并聚焦地址
    ↓
查看上下游和多层关系
    ↓
查看实时 USDT 与其他资产
    ↓
查看资金规模、结构和活跃度统计
    ↓
点击边核验交易明细
    ↓
保存路径和余额证据
    ↓
启动 Investigation Agent
```

## 2. 设计原则

1. 复用现有 ReactFlow，不引入新的图形库。
2. 聚焦图必须从完整数据计算，不能只基于全局 Top 600 边。
3. 实时余额查询必须异步执行，不阻塞图谱渲染。
4. 余额查询失败不得显示为 0。
5. 实时余额、缓存余额和历史快照必须明确区分。
6. 图边净流量不等于地址当前余额，也不等于利润。
7. 所有统计必须标明链、Token、时间范围和完整性。
8. 所有关键结论必须可以追溯到交易哈希、区块或 RPC 查询区块。
9. 节点尺寸不得因余额加载而变化，避免布局跳动。
10. 缩放和平移只修改 viewport transform，不触发业务数据重算。

## 25. 性能要求

图形：

- 全局边默认 ≤ 600
- 聚焦边默认 ≤ 200，最大 500
- 40 次快速缩放无 DOM 数量波动
- 交互期间暂停边动画和阴影
- `vector-effect: non-scaling-stroke`
- 节点、边使用 `React.memo`
- `nodeTypes/edgeTypes` 模块级常量

资产：

| 指标 | 目标 |
|---|---|
| 中心 USDT | P95 < 1.5 秒 |
| 中心重点资产 | P95 < 3 秒 |
| 20 地址 × 3 Token | P95 < 5 秒 |
| 缓存命中 | < 50ms |

加载顺序：

```text
先显示图
↓
显示缓存统计
↓
查询中心余额
↓
查询直接邻居
↓
空闲查询其他可见节点
```

## 26. 限流与安全

必须：

- 地址格式验证
- Token 地址格式验证
- 批量上限
- 全局和单 RPC 并发上限
- 请求超时和 context cancel
- API Key 不回显
- RPC 错误脱敏
- 429 返回 `Retry-After`
- 前端不无限重试
- 旧请求使用 AbortController 取消
- 所有缓存和快照禁止写入 C: 盘

## 27. 异常处理

RPC 全部失败：

```text
实时余额查询失败
图谱和历史统计仍可使用
```

Token 部分失败：

```text
USDT success
USDC timeout
FIST invalid_response
```

状态返回：

```text
partial
```

图被截断：

```text
当前图已截断
```

## 30. Codex 实施规则

1. 不引入新图形库。
2. 不破坏现有 `/api/flow/build`。
3. 聚焦查询复用现有方向标准化。
4. 实时余额异步，不阻塞图。
5. 查询失败不得返回伪 0。
6. 余额必须带 block number 和 queried_at。
7. 统计必须注明范围和完整性。
8. 节点尺寸不得因余额加载变化。
9. wheel/pointermove 不更新业务状态。
10. `nodeTypes/edgeTypes` 不在 render 内创建。
11. API 必须有批量和并发限制。
12. 不允许向 C: 盘写任何数据。
13. 修改后必须执行前端构建、Go 测试和真实链验收。
