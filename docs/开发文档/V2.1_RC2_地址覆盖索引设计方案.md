# V2.1 RC2 地址覆盖索引设计方案

版本：V2.1 RC2\
状态：设计方案\
目标：解决50万地址规模下的数据覆盖判断、增量采集和重复下载问题

------------------------------------------------------------------------

# 1. 背景

当前系统已经具备：

-   Provider Router
-   Dataset Registry
-   Parquet Data Lake
-   DuckDB分析能力
-   Checkpoint恢复能力

随着真实BSC地址规模扩大，需要解决：

-   某地址是否已经采集
-   某地址覆盖哪些区块范围
-   哪些地址需要重新下载
-   新任务如何避免重复请求

因此增加：

> Address Coverage Index（地址覆盖索引）

------------------------------------------------------------------------

# 2. 设计目标

实现：

    输入地址列表

    ↓

    查询覆盖索引

    ↓

    过滤已有数据

    ↓

    只采集缺失部分

    ↓

    更新覆盖记录

目标：

-   降低SQD请求量
-   降低RPC压力
-   提升任务速度
-   支持百万地址管理

------------------------------------------------------------------------
