# V2.1 RC2 链上分析平台菜单结构调整方案

版本：V2.1 RC2

## 1. 调整目标

当前菜单存在：

-   地址分析入口重复
-   数据管理与业务分析混合
-   底层技术功能暴露过多

目标调整为：

从"区块链工具后台"升级为"链上数据分析平台"。

------------------------------------------------------------------------

## 2. 新菜单结构

    🏠 Dashboard

    📦 数据资产

    🔍 链上分析

    📄 报告中心

    ⚙ 系统设置

一级菜单控制在 5 个以内。

------------------------------------------------------------------------

## 3. Dashboard

展示：

-   地址数量
-   Token数量
-   数据规模
-   分析状态
-   风险趋势
-   快速入口

------------------------------------------------------------------------

## 4. 数据资产

负责数据基础能力：

    数据资产

    ├ 数据集管理
    ├ 数据下载
    ├ Parquet仓库
    ├ 数据源管理
    └ RPC节点管理

说明：

-   Parquet下载属于数据资产，不直接暴露在主菜单
-   RPC、Provider属于系统资源管理

------------------------------------------------------------------------

## 5. 链上分析

核心业务入口：

    链上分析

    ├ 地址分析
    ├ 资金流分析
    ├ Token资产分析
    ├ 地址图谱
    └ 风险分析

覆盖：

-   地址画像
-   资金追踪
-   Token余额
-   关系网络
-   风险识别

------------------------------------------------------------------------

## 6. 报告中心

统一管理：

-   分析报告
-   HTML报告
-   JSON报告
-   证据数据

------------------------------------------------------------------------

## 7. 系统设置

管理：

-   服务状态
-   日志
-   配置
-   系统信息
