# 资金流向图（白底单人版）深度优化设计 V1.0
## 面向单人调查场景的地址关系图 / 资金路径图重构方案
### 目标：参考市面链上分析工具的强项，但与现有 Smart Download / 数据资产 / 智能调查体系深度联动

> 适用对象：**单人使用**
>
> 核心定位：
>
> 不是做一个“通用炫酷大图”，而是做一个**单人高效率调查工作台**：
>
> - 图要**看得清**
> - 数据要**点得动**
> - 结果要**能追踪**
> - 资金路径要**能深挖**
> - 已下载数据要**立刻复用**
> - 缺失数据要**自动补齐**
> - 图、结果、调查、下载要**联成一个闭环**

---

# 1. 核心结论

当前这张图的主要问题，不是“功能太少”，而是：

```text
1. 图太密、太暗、可读性差
2. 白天长时间使用容易疲劳
3. 节点和边虽然很多，但调查效率不高
4. 右侧详情与画布联动不够强
5. 与智能下载 / 结果数据 / 智能调查的闭环还不够深
6. 没有真正针对“单人调查工作流”优化
```

因此建议下一阶段不要只是“换个背景颜色”，而是直接做一版：

```text
资金流向图 V2（白底单人深度优化版）
```

核心策略：

```text
视觉减噪
+
调查工作流重构
+
路径分析优先
+
结果联动优先
+
单人效率优先
+
自动补数优先
```

---

# 2. 产品定位重新定义

新的资金流向图不是一个“孤立图谱页”，而应该是：

```text
数据资产
↓
资金流向图
↓
路径判断
↓
实体识别
↓
结果固定
↓
智能调查
↓
调查报告
```

也就是说：

> **资金流向图是整套系统的“交互分析核心面板”，不是简单的可视化页。**

# 3. 总设计目标

本次优化要同时满足 6 个目标：

## 3.1 看得清

- 白底
- 高对比
- 低噪声
- 信息层级清晰
- 缩放时不糊、不乱

## 3.2 找得快

- 快速搜索地址 / 实体
- 快速定位上游 / 下游 / 前后追踪
- 快速筛选关键边和关键节点
- 快速切换路径视角

## 3.3 点得准

- 节点选中高亮明确
- 边选中可读
- 详情面板实时联动
- 不再“点半天点不到”

## 3.4 追得深

- 支持多跳扩展
- 支持关键路径
- 支持沉淀 / 交易所 / 获利视图
- 支持实体折叠 / 地址展开

## 3.5 跑得动

- 大图自动聚合
- 按层加载
- 只渲染必要信息
- 单人用优先，不做过度协同开销

## 3.6 联得上

- 跟智能下载联动
- 跟结果数据联动
- 跟地址画像联动
- 跟智能调查联动
- 跟报告联动

# 4. UI 总体改造方向

建议把当前深色大图改成：

```text
白底主画布
+
浅灰网格
+
蓝色主交互
+
风险 / 交易所 / 关键路径用强调色
+
右侧详情面板保留
+
顶部工具条保留但重构
```

# 5. 为什么必须改成白底

你是**单人高频使用**，不是展示型大屏。

深色图谱虽然“酷”，但长期问题明显：

- 长时间盯屏疲劳；
- 边和文字在大量节点下容易糊；
- 截图导出后阅读性差；
- 打印 / 写报告时不友好；
- 深色背景下风险色 / 高亮色容易互相抢。

对于单人调查工作台，白底更适合：

```text
长时间分析
截图汇报
报告嵌入
信息标注
节点阅读
```

# 6. 视觉设计原则

## 6.1 白底不是纯白

建议：

```text
主背景：#F7F9FC
画布卡片背景：#FFFFFF
浅网格线：#E9EEF5
边界分割线：#E5EAF1
主文字：#1F2937
次文字：#6B7280
弱文字：#94A3B8
```

避免“医院白”的刺眼感。

---

## 6.2 节点和边的颜色层级

### 节点类型颜色建议

- 当前选中地址：主蓝色
- 上游来源：青蓝
- 下游去向：橙色
- 交易所 / 服务实体：绿色
- 风险地址：红色
- 未聚类普通地址：灰蓝
- 合约 / Router / Pool：紫色
- 沉淀地址：深青色
- 获利地址：金橙色

### 边颜色建议

- 普通边：浅灰蓝
- 选中路径：主蓝
- 上游边：青蓝
- 下游边：橙色
- 风险相关边：红色
- 交易所落点边：绿色
- 回流边：紫红色
- 低权重弱边：透明浅灰

# 8. 顶部工具条重构

当前顶部已经有：

- 1 层 / 2 层 / 全部
- 关系类型

---

## 8.1 顶部左侧：搜索与定位

```text
[地址 / 实体 / Tx Hash 搜索框]
[定位]
[从该地址开始追踪]
```

支持：

- 输入地址直接定位；
- 输入实体名（后续 Entity Intelligence）；
- 输入 TxHash 跳到交易边；
- 输入后支持历史记录。

---

## 8.2 顶部中部：视图模式

建议改成显式模式切换，而不只是“方向”。

```text
[普通图]
[关键路径]
[实体图]
[沉淀图]
[获利图]
[交易所落点]
```

这会大幅提升调查效率。

### 普通图
显示基础地址关系。

### 关键路径
只显示高分路径，噪声边折叠。

### 实体图
按 Entity 折叠，不看每个零碎地址。

### 沉淀图
强调净沉淀与长期保留地址。

### 获利图
强调净获利地址与路径。

### 交易所落点
强调交易所 / 托管服务方向。

---

## 8.3 顶部右侧：图操作

```text
[上游]
[下游]
[前后]
[1层]
[2层]
[3层]
[全部]
[自动布局]
[聚合]
[重置]
```

再增加：

```text
[只看关键节点]
[隐藏弱边]
[隐藏小额]
```

# 10. 中间画布优化

这是本次最重要的部分。

---

## 10.1 画布默认状态

当前一上来就是“密密麻麻大图”，容易劝退。

建议改为：

```text
先聚焦根地址
↓
只加载初始核心邻居
↓
用户主动扩展
```

默认展示：

- 根地址；
- Top 上游；
- Top 下游；
- 高价值 / 高频 / 已知实体优先；
- 低价值噪声暂不展开。

---

## 10.2 渐进展开

不要一次展开 600 节点。

建议：

```text
展开 1 层
→ 优先关键节点
→ 用户点击某节点
→ 展开该节点下一层
```

这对单人调查最好。

---

## 10.3 自动聚合

当某节点的下游太多时，不要全部铺开。

例如：

```text
交易所 Deposit 关联 180 个地址
```

显示为：

```text
[180 个相关地址]
```

可以点击展开。

---

## 10.4 图谱层级

建议支持 3 层渲染粒度：

### 粒度 1：实体级
例如：

```text
Exchange X
Collector Cluster
Unknown Service Cluster
```

### 粒度 2：聚类级
例如：

```text
20 Deposit Addresses
```

### 粒度 3：地址级
真正展开单地址。

用户可逐层钻取，而不是一上来全部地址级。

# 11. 节点设计优化

## 11.1 节点卡片设计

不要所有节点都显示同样长的文字。

节点信息建议最少包含：

```text
主标签（实体名/地址简写）
副标签（类型）
金额/交互数摘要
```

例如：

```text
Exchange X
CEX Deposit
120K USDT
```

或者：

```text
0x1234…89ab
未标记地址
3 笔 / 58K
```

---

## 11.2 节点形状

建议通过形状做辅助区分：

- 普通地址：圆角矩形
- 实体：加粗圆角矩形
- 合约：六边形 / 特殊矩形
- 风险：带红边
- 根地址：蓝色高亮 + 外圈
- 聚类节点：分组样式
- 沉淀地址：深色边框
- 交易所：绿色标识

---

## 11.3 节点状态小图标

在节点上增加弱提示 icon：

- E：交易所
- R：风险
- C：合约
- P：路径重点
- S：沉淀
- G：获利
- L：本地已缓存 / 已验证数据

要小，不要喧宾夺主。

---

# 12. 边设计优化

## 12.1 边上不再默认展示过多文字

当前大图里文字密度过高。

建议默认：

- 普通缩放下仅展示边方向和粗细；
- 选中后展示金额 / 次数 / 时间；
- 放大到一定级别后再显示详细标签。

---

## 12.2 边宽度编码

边宽度可表示：

```text
金额大小
或
交易次数
```

建议默认按：

```text
USD Value / 累计金额
```

编码。

---

## 12.3 边样式

- 实线：普通直接转账
- 虚线：推断路径 / 低置信
- 双线：多笔聚合
- 箭头：方向明确
- 波浪 / 特殊标记：跨链桥 / Swap

---

## 12.4 边标签内容

选中后展示：

```text
累计金额
交易次数
最近时间
主要 Token
路径类型
```

例如：

```text
USDT 128K
12 笔
最近 2026-08-08
类型：归集
```

# 15. 市面工具应借鉴的能力（泛化为能力，不照搬界面）

需要借鉴的不是皮肤，而是能力模型。

---

## 15.1 借鉴能力 A：图谱可控性

市面优秀图工具通常都有：

- 分层展开；
- 动态筛选；
- 节点聚合；
- 关键节点保留；
- 弱边折叠。

你这套系统也必须重点做。

---

## 15.2 借鉴能力 B：地址 / 实体双视角

不能只有地址图。

你已经规划了 Entity Intelligence，所以一定要把：

```text
地址图
↔ 实体图
↔ 混合图
```

做成核心能力。

---

## 15.3 借鉴能力 C：路径优先而非全量优先

优秀链上分析工具，不是把所有节点堆出来，而是：

```text
优先让你看到“有意义的部分”
```

因此要强化：

- 关键路径
- 交易所落点
- 获利路径
- 沉淀路径
- 回流路径

---

## 15.4 借鉴能力 D：节点工作流

用户点节点后要能继续行动，而不只是看详情。

你的系统应该做到：

```text
点节点
→ 详情
→ 补数
→ 路径
→ 地址画像
→ 智能调查
→ 报告
```

这就是你相对市面工具的优势。

---

# 16. 与你的系统深度联动（这是最关键差异点）

这是你不应该只“参考市面工具”，而要**超过它们**的地方。

---

## 16.1 与 Smart Download 联动

当图上点开某个未覆盖地址时：

而不是用户自己退出去下载。

## 16.2 与结果数据联动

图上选中节点后：


直接跳到结果页并带过滤条件：

- address
- chain
- dataset
- time range
- token

## 16.3 与地址画像联动

图上选中节点后：

```text
[地址画像]
```

直接打开画像并继承当前地址。

---

## 16.4 与智能调查联动

图上选中：


支持：

- 作为关键地址加入；
- 作为路径节点加入；
- 作为沉淀候选加入；
- 作为交易所落点加入；
- 作为风险节点加入。

---

## 16.5 与 Report Engine 联动

图上任何一条关键路径、节点、沉淀结论，都可以：

```text

```

或者：

```text
[生成路径说明]
```

# 17. 针对单人场景的专门优化

你已经说了：**单人用就行**。这会影响很多设计取舍。

---

## 17.1 去掉多人协同复杂度

本阶段不要优先做：

- 实时协作光标
- 多人注释冲突
- 共享编辑
- 审核流
- 复杂权限

这些先不做。

---

## 17.2 强化个人工作流

单人最需要的是：

- 快速标记
- 快速固定节点
- 快速收藏路径
- 快速写笔记
- 快速导出
- 快速恢复上次画布状态

---

## 17.3 个人工作区

建议增加：

```text
我的标记
我的关键节点
我的重点路径
我的临时备注
最近查看
画布快照
```

存在本地 / 案件工作区里即可。

---

单人调查极其需要。

支持：

```text
保存当前图状态
```

包括：

- 根地址

- 模式
- 展开层级
