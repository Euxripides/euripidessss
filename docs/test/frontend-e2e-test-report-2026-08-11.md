## 4. 发现与说明

1. **资金追踪页 / 分析总览**：控制台与网络层出现 `/api/analytics/graph` 503（warehouse 数据未就绪）。这是既有环境依赖问题（API 测试报告 BUG-11），页面本身正常渲染，不属于本轮新增 Bug。
2. **Explorer 交易 Tab 默认空态**：锚点地址最近一笔交易在默认 30D 时间窗外，界面正确显示“没有符合当前筛选条件的数据”并支持清筛选/切换 ALL；切到 ALL 后数据正常展示，详情抽屉可打开。属预期行为，非 Bug。
3. **案件页 404 回归已修复**：上一轮为调查接口增加“不存在即 404”时误伤 `/api/investigations/default/reports`（案件工作区默认调查），已修复（default 视为存在）并通过本 E2E 验证。
4. **上传流程真实执行**：`POST /api/process` 返回 200，清洗流程启动并轮询进度；测试后已清理。
