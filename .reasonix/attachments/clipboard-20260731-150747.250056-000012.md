# V2.1 RC2 本地Parquet数据资产库设计方案

版本：V2.1 RC2\
状态：设计方案\
目标：构建低成本、高性能、可持续积累的BSC链上数据资产库

------------------------------------------------------------------------

# 1. 背景

当前系统已经完成：

-   SQD Provider真实链验证
-   StreamLogs验证
-   StreamTraces验证
-   Provider Router
-   Failover设计
-   DuckDB分析能力
-   Parquet写入能力

现实约束：

-   不购买商业索引服务
-   不运行BSC Archive Node
-   SSD容量有限
-   SQD公共服务存在波动

因此采用：

> 一次采集，多次分析

的数据资产模式。

------------------------------------------------------------------------

# 2. 设计目标

建立：

    BSC数据

    ↓

    Provider采集

    ↓

    Parquet资产库

    ↓

    DuckDB分析

    ↓

    持续复用

目标：

-   避免重复下载
-   降低Provider依赖
-   支持百万地址分析
-   支持长期数据积累
