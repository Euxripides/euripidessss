# V2.1 RC2 Dataset Registry增强设计方案

版本：V2.1 RC2  
状态：设计方案

---

# 1. 背景

当前系统已具备：

- Provider Adapter
- Provider Router
- SQD容灾设计
- Parquet数据资产库
- DuckDB分析能力
- Checkpoint恢复能力

随着真实BSC数据积累，需要管理：

- 数据是否已经下载
- Block覆盖范围
- 地址覆盖范围
- 文件完整性
- 增量更新
- 任务恢复

因此增强 Dataset Registry。

---

# 2. 设计目标

Dataset Registry负责：

```
数据发现
↓
覆盖判断
↓
任务去重
↓
增量下载
↓
完整性验证
↓
生命周期管理
```

---

# 3. 总体架构

```
Query Request

↓

Dataset Registry

↓

+----------------+

|                |

Parquet       Provider Router

|                |

DuckDB       SQD / RPC
```

# 16. 测试

## 重复任务

第一次下载。

第二次直接命中缓存。


## 中断恢复

下载50%后退出。

恢复失败Chunk。


## 文件损坏

Checksum失败。
