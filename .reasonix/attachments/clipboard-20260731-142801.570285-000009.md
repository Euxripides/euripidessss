# V2.1 RC2 SQD容灾设计方案

版本：V2.1 RC2\
状态：设计方案

## 1. 背景

当前系统已完成：

-   Provider Adapter
-   Health
-   Capability
-   Router
-   Failover
-   Checkpoint
-   Dataset Registry

真实测试发现 SQD 可以获取真实 BSC 数据，但存在：

-   DNS异常
-   503限流
-   网络波动
-   服务不可达

目标：

实现 Provider级容灾、Chunk级恢复、Dataset级幂等。

## 3. Provider Health Score

增加：

``` go
type ProviderScore struct {
 Provider string
 SuccessRate float64
 AvgLatency int64
 ErrorCount int
 Status string
}
```

根据：

-   成功率
-   延迟
-   错误次数
-   最近失败

计算Provider评分。

------------------------------------------------------------------------

## 4. Circuit Breaker

状态：

    Healthy
     ↓
    Degraded
     ↓
    Open
     ↓
    Half Open
     ↓
    Recovery

规则：

连续5次失败：

进入Open。

Cooldown：

60秒。

------------------------------------------------------------------------

## 5. Chunk级Failover

禁止整个Job切换。

采用：

    Chunk001 SQD DONE
    Chunk002 SQD DONE
    Chunk003 SQD FAILED
    Chunk004 SQD DONE

只恢复失败Chunk。

------------------------------------------------------------------------

## 6. Retry策略

网络错误：

    1s
    2s
    5s
    10s
    30s

503：

Cooldown 30-60秒。

429：

降低并发并等待。

400：

不重试。

------------------------------------------------------------------------

## 8. Dataset恢复
