# 5. Agent体系设计


## 5.1 Investigation Planner Agent

职责：

制定调查计划。


输入：

```
目标地址
地址画像
风险指标
资金概览
```


输出：

```
调查任务：

1. 分析资金来源

2. 分析主要流向

3. 追踪高价值路径

4. 检查实体关系
```


---

## 5.2 Fund Tracing Agent

职责：

资金逐笔穿透。


能力：

- 多跳追踪
- 时间分析
- 路径构建
- 资金生命周期分析


示例：

```
A

↓

100000 USDT

↓

B

↓

95000 USDT

↓

C
```


记录：

- tx_hash
- block_number
- token
- amount
- timestamp


---

## 5.3 Entity Intelligence Agent

负责地址身份识别。


分类：

```

contract

unknown
```


识别依据：

- 交易行为
- 对手数量
- 资金模式
- 标签库

# 6. 智能资金追踪算法


不采用简单 BFS。


采用：

## Beam Search

控制路径数量。


流程：

```
发现路径

↓

计算评分

↓

保留Top K

↓

继续深入
```


---

## Path Ranking

评分：

```
PathScore =

金额权重

+

时间连续性

+

风险权重

+

关系强度

-

实体惩罚
```


---

## Temporal Graph

加入时间维度。


普通图：

```
A-B
```


升级：

```
A

2026-01-01

100 USDT

tx_hash

↓

B
```

# 7. 自动地址扩展

流程：

```

↓

实体识别

↓

Expansion Score

↓

决定是否扩展
```


评分：

```
Expansion Score =

资金规模

+

风险

+

路径重要性

+

未知程度

-

交易所惩罚
```
